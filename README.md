Bank Management System

A web-based Bank Management System developed using Python, Flask, and MySQL.

## Features

•⁠  ⁠User Registration and Login
•⁠  ⁠Secure User Authentication
•⁠  ⁠Bank Account Management
•⁠  ⁠Deposit Money
•⁠  ⁠Withdraw Money
•⁠  ⁠Transfer Money
•⁠  ⁠Transaction History
•⁠  ⁠User Profile
•⁠  ⁠MySQL Database Integration

## Technologies Used

•⁠  ⁠Python
•⁠  ⁠Flask
•⁠  ⁠MySQL
•⁠  ⁠HTML
•⁠  ⁠CSS
•⁠  ⁠JavaScript

## Project Description

This project is designed to manage basic banking operations through a web-based interface. Users can create an account, log in securely, manage their bank accounts, deposit and withdraw money, transfer money, and view their transactions.
